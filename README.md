# Brand Assets

Official brand assets for Bitcast, Stitch3, and Outfold.

## Structure

```
brand/
├── logo/        # Full logos (icon + wordmark)
├── icon/        # Standalone icons/marks
├── wordmark/    # Text-only logos
└── colors/      # Color palettes and swatches
```

Each asset directory contains source SVGs and any exported variants.

## Brands

- **[Bitcast](bitcast/)** — Decentralized marketing infrastructure on Bittensor
- **[Stitch3](stitch3/)** — Creator campaign platform by Bitcast
- **[Outfold](outfold/)** — Product & design brand (creator portal, outfold.ai)

## Usage

SVG is the canonical format. Use these for all digital and print applications.

## Adding a New Brand

Create a new top-level directory following the same structure above.
